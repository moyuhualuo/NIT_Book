# 寒暑假留校学习的建议

> 关于暑假留校，起初是听到某院负责人谈起让他儿子留校的事情，我才认识到，在暑假留校的重要性。最重要的是学更多的课程！

### 学更多的课程
- 暑期留校，有时间开更多的CS课程，也可以更加系统的学习某方面的知识或者预习某方面的知识，例如：高数、线代、离散、英语4、6级、Java项目、go/golang项目 ... 有社团实验室的留校目的是为比赛、老师的项目资源上下功夫。如果是散修，你的幸运点是可以学自己感兴趣的，但切记学习的导向要符合商业化的社会！我们目前还不能真正的散修！
### 自控力方面
- 留校学习可以帮助你培养更强的自控力。在学校的环境中，你可以更容易地制定和遵守学习计划，避免在家中可能遇到的各种干扰。

### 生活适应方面
- 留校期间，独立生活。你需要自己安排饮食、作息和学习时间，这有助于提高生活自理能力和时间管理能力。

### 真正的上进
- 在学校的学习氛围中，你可以更专注于学业，避免在家中可能出现的懒散和拖延。

### 必须留校的情况
- 考虑到二本学生的差异型，如果要自学考研，则留校是你的100%选择，图书馆不开方，租个自习室，或在宿舍学习。
- 雅思托福不太清楚，如果为了申请国外研究生的话，至少要6.0以上，GPA3.0以上，自学的话还是建议留校，除报相关机构。

> 寒假因为要过年回家，这时候可以复现你的锻炼成过，在不上心，浑浑噩噩的话，就少点自责，多些平淡心，不要有那么多高的追求。
