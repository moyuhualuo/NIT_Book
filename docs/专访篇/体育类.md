# 体育队类专访

访谈是客观的，真实的，希望此类有用于你，淋过雨或许就想撑伞。因为篇幅原因，只截取部分。

### 校篮球队访谈

> 22 计软篮球队李昊洁：

- **Liu**：为什么选择篮球队？
- **Li**：我选择加入篮球队，主要因为对篮球的热爱，我觉得篮球是一项竞技运动，喜欢篮球就是对这种竞技的热爱。其次就是希望通过团队运动锻炼自己的团队协作能力。最后在希望通过训练在比赛中展现在自己，这能给我不仅仅是生活中学习中的很多自信。
- **Liu**: 更多的是热爱，什么事情都要有兴趣。对身心上的实际感受收益如何？
- **Li**：篮球首先有助于提高身体素质，增强心肺功能，提高新陈代谢，对我们的健康有很大的帮助同时也可以培养坚韧不拔、永不放弃的精神品质。篮球也有助于释放压力，在你心情不好的时候，可以自己去打打篮球，篮球不会说话，享受这种沉浸的时刻会让自己的身心得到放松。篮球同时也可以结识志同道合的朋友，篮球让我们聚在一起，同时也能扩大自己的人脉关系。缺点就是训练和比赛需要花费时间比较多，可能影响学业和其他活动。但是，篮球运动中的团队协作、沟通能力很重要，在比赛中需要积极和队友沟通，比如防守方面的问题等。其中篮球带给我不放弃坚持不懈的精神是无价的。
- **Liu**：身体是革命的本钱，健康很重要，有时需要权衡下学习和健康的位置。篮球队的关注度很高，每次你们比赛就会有很多人围观，那么队内的比赛实际奖励有什么？
- **Li**：篮球比赛有机会获得奖杯、荣誉等物质和精神奖励。
- **Liu**：体育类竞赛对综测加分也是附加的益处，那么如果再选一次，你还会参加吗？
- **Li**：会，如果我对篮球的热爱依然如初，我会选择继续加入篮球队。因为在篮球队的经历让我收获了成长、友谊和难忘的回忆，和无法用金钱衡量的坚持精神。篮球带给我了很多！
- **Liu**：嗯，友谊和成长我想比无意义的内卷显得更有价值。
